# Учебное портфолио

Цель проекта — создать учебный сайт-портфолио и попрактиковаться в работе с чистыми HTML, CSS и JavaScript. Используются только вымышленные примеры и данные.

## Файлы сайта

Предусмотрены три файла сайта:

- `index.html` — структура страницы и разделы портфолио.
- `style.css` — оформление, стили и адаптация под разные размеры экрана.
- `script.js` — интерактивное поведение страницы.

## Как открыть сайт

Когда файлы сайта созданы, откройте `index.html` двойным щелчком или через меню браузера «Открыть файл». Установка пакетов, сборка и сервер не требуются.

Правила работы с проектом описаны в `AGENTS.md`.
