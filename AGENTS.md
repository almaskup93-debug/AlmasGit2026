# Правила работы с учебным портфолио

- Использовать только чистые HTML, CSS и JavaScript, без библиотек и фреймворков.
- Сохранять существующие разделы сайта: не удалять и не заменять их без явного указания пользователя.
- Не устанавливать пакеты и зависимости, не добавлять и не запускать сборку.
- Не использовать Git и не выполнять команды Git.
- Не подключать API и внешние сервисы.
- Не публиковать и не развёртывать сайт.
- Не добавлять реальные персональные, контактные или иные реальные данные. Для учебных примеров использовать явно вымышленные данные и заглушки.
- После каждой правки перечислять внесённые изменения и честно указывать выполненные проверки и их результаты. Если проверки не выполнялись, сообщать об этом прямо; не заявлять об успешных проверках без их выполнения.
